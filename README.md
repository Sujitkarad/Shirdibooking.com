# Shirdibooking 🛺

A simple local auto-rickshaw booking platform for visitors and residents in **Shirdi, Maharashtra**.

## About

Shirdibooking is designed to make booking an auto-rickshaw in Shirdi easier. Customers can use the platform to get in touch for local rides, temple visits, railway/bus station transfers, and Shirdi sightseeing.

## Services

- 🛺 Local auto-rickshaw rides in Shirdi
- 🛕 Sai Baba Temple visits
- 🚉 Shirdi railway station transfers
- 🚌 Bus stand transfers
- 📍 Local sightseeing and Shirdi tour rides
- 📞 Direct booking and customer support

## Pricing

- Shirdi tour package: **₹999**
